# 将 scoop (安装的软件) 安装到离线环境

## 目标

使用一些脚本, 快捷地打包离线安装所需内容. 需要在离线环境中已经安装了 scoop 的情况下使用.

## 原理

迁移 buckets 和安装包, 让离线环境的 scoop 认为 buckets 更新完毕且安装包已经下载好, 以此直接进行安装.

侵入性小. 即使是离线环境后来能连上网, 接着使用也是没有任何影响.

相对整个 scoop 文件夹迁移更快捷, 且整个迁移可能会破坏 persist 数据

## 依赖

- 环境中安装了 7z
- 环境变量 SCOOP 指向了 scoop 的安装目录

如果没有, 请在执行脚本前手动引入一下, 例如执行 `$env.SCOOP = C:\scoop`

## 特性

- 第一次运行导出时, 会生成 list.toml. 比起 json 更加易读. 你可以手动修改 list.toml 决定哪些要导出, 哪些不要
- 导入时不需要 list.toml. 因此你可以手动打包安装包, 届时脚本同样会替你安装 (但 buckets 得保证比最新的安装包更新).
